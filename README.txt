INK MAGIC - Tattoo Lucky Spin

Run on Windows:
1. Extract the ZIP.
2. Open CMD in this folder (click the folder address bar, type cmd, Enter).
3. Run: py -m venv venv
4. Run: venv\Scripts\activate
5. Run: pip install -r requirements.txt
6. Run: python app.py
7. Open http://127.0.0.1:5000 in your browser.

Prize weights are in app.py under PRIZES. Weight is relative, not a direct percentage.
This is a starter/demo app. It currently does not save customer entries or results to a database.
Internet is needed for the optional Google Font; the site otherwise works without it.
